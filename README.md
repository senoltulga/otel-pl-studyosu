# Otel P&L Stüdyosu

Otel bütçesi için P&L, KPI, geri dönüş, DCF ve renovasyon hesaplayan tek dosyalık web uygulaması.
Kayıtlar Supabase'de (e-posta ile giriş), girişsiz kullanımda tarayıcıda tutulur.

- `index.html`: tüm uygulama (supabase-js CDN'den yüklenir)
- Supabase tablosu: `opl_cases` (satır güvenliği açık, herkes yalnız kendi kayıtlarını görür)

Karar destek aracıdır, yatırım tavsiyesi değildir.
